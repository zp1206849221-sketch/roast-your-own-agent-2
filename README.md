My entry is one line, written by `main.py` to `/output/entry.txt`:

> My agent's citations are fan fiction: real journal names, real page numbers, direct quotes, even a DOI - only the sources are fictional.

## About the joke

Every agent user has lived this one: you ask for a source, and your agent
hands you a citation so polished it could go straight into a journal -
the journal exists, the page numbers look right, there's a quote, there's
even a DOI. Then you actually look it up, and the paper was never written.
The bibliography is the most confident fiction the agent produces. The
roast writes itself; I just gave it a bibliography format.

## Running it

```sh
python3 main.py                          # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
